# Sistema de Gestión Comercial

Sistema en Python para gestionar productos, ventas, inventario y reportes de un negocio.

## Cómo ejecutarlo
1. Instalar Python 3.
2. Descargar el repositorio.
3. En la terminal, dentro de la carpeta del proyecto: python src/main.py

## Módulos
- productos.py: registrar, consultar y modificar productos.
- ventas.py: registrar ventas con IVA del 12 %.
- inventario.py: existencias, entradas y stock mínimo.
- reportes.py: estadísticas y reportes.
- archivos.py: lectura y escritura de archivos CSV.
- estructuras.py: matrices y validaciones.
